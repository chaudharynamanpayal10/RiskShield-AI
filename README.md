# 🛡️ RiskShield AI

AI-powered transaction risk analysis and fraud detection system.

## 🚀 Features

- 🔐 User Signup & Login
- 🔑 JWT Authentication
- 🤖 AI-based Transaction Risk Analysis
- 📊 Risk Score from 0–100
- ⚠️ Low, Medium and High Risk Classification
- 🚫 Automatic Transaction Blocking
- 📈 Risk Dashboard
- 📋 Transaction History
- 🚨 Risk Alerts
- 🗄️ MongoDB Transaction Storage
- 🔒 Protected User Transactions

## 🏗️ Tech Stack

### Frontend

- CSS

### Backend
